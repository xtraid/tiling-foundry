Open with the problem and the result. The layout supplies the title, date,
reading time, navigation, and Wang visualization automatically.

## Context

Explain the relevant invariant, implementation boundary, or experiment in
ordinary Markdown. Authors do not need to add animation metadata, HTML, or
JavaScript.

## Method

Use normal Markdown structures:

1. state the setup;
2. record the procedure;
3. separate observations from conclusions.

```text
north(A) = south(B)
```

## Result

Close with the evidence, limitations, and the next falsifiable question.
